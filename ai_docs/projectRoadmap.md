# Project Roadmap

## Project Overview

Green Office Labels (aka go-labels) is a web-based sustainability assessment system for student organizations of the University of Groningen (UG). Organizations complete questionnaires and receive sustainability certifications based on their responses. The project includes a questionnaire management system for the Green Office, a questionnaire answering portal for organisations, automatic and manual response verification for answers, reporting and analytics.
