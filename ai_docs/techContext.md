# Technical Context

## Tech Stack

- **Frontend**: SvelteKit 2.0 with SSR, Svelte 5
- **Styling**: shadcn-svelte components with Tailwind CSS
- **Backend**: Sveltekit, Appwrite
- **Build System**: Vite
- **Package Manager & Deployment server**: bun

## Development Setup

- Running the dev server: `bun --bun run dev`
- Typescript for type safety
- ESLint and Prettier for code quality
- Test-Driven development
